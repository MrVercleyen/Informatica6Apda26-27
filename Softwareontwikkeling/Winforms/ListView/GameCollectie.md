# Oefening 1 – Game Collectie

Maak een eenvoudige **WinForms-applicatie** waarin je een verzameling videogames kunt beheren.

## Opdracht

Maak een formulier waarin de gebruiker videogames kan toevoegen aan een lijst.

Voorzie invoervelden voor:

- Naam van de game
- Platform (PC, PlayStation, Xbox, Switch)
- Genre
- Releasejaar

Gebruik een **ListView** om alle games weer te geven.

### Werking

Wanneer de gebruiker op **Toevoegen** klikt:

1. Lees alle ingegeven gegevens uit.
2. Voeg een nieuwe rij toe aan de ListView.
3. Toon alle gegevens in de juiste kolommen.
4. Maak de invoervelden leeg.

Wanneer de gebruiker op **Verwijderen** klikt:

1. Selecteer een game in de ListView.
2. Verwijder de geselecteerde game.
