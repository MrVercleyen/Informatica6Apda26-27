# Boodschappen

Maak een eenvoudige boodschappenlijst met Windows Forms.

## Opdracht

Maak een WinForms-applicatie waarin de gebruiker boodschappen kan toevoegen aan een lijst.

### Een boodschap bestaat uit:

- naam

- aantal

Voorzie invoervelden, een knop Toevoegen en een plaats waar de boodschappenlijst wordt getoond.

## Klasse

Maak een aparte klasse ShoppingItem.

Deze klasse bevat de gegevens van één boodschappenitem:

- Naam
- Aantal

Gebruik properties om deze gegevens te bewaren.

## Werking

Wanneer de gebruiker op Toevoegen klikt:

- Lees de naam en het aantal uit.

- Maak een nieuw ShoppingItem-object.

- Voeg dit object toe aan de boodschappenlijst.

- Toon de boodschappen in de WinForms-applicatie.
