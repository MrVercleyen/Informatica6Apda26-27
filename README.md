## Lokaal binnenhalen

Je kan alle bestanden makkelijk binnenhalen door de repository te clonen

```
git clone https://github.com/MrVercleyen/Informatica6Apda26-27.git
```

Het is belangrijk dat je niets wijzigt in deze repository op jouw eigen computer.
Anders zal je later conflicten krijgen wanneer je tracht updates binnen te halen.

Om updates binnen te halen voer je volgend commando uit in Git Bash in de repository.

```
git pull
```
