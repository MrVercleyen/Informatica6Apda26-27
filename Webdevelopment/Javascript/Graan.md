# Graan

Er was eens een wijze dienaar die het leven van een prins redde. De koning beloofde hem alles te geven wat hij maar kon bedenken. Omdat hij wist dat de koning dol was op schaken, zei de dienaar tegen de koning dat hij graag tarwekorrels wilde hebben: één korrel op het eerste veld van een schaakbord, waarbij het aantal korrels op elk volgend veld verdubbelt.

## Opdracht

Bereken het aantal tarwekorrels op een schaakbord.

Een schaakbord heeft 64 velden. Op veld 1 ligt één graankorrel, op veld 2 liggen twee graankorrels, op veld 3 liggen vier graankorrels, enzovoort, waarbij het aantal telkens verdubbelt.

Schrijf code die het volgende berekent:

- het aantal graankorrels op een bepaald veld
- het totale aantal graankorrels op het schaakbord
